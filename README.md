# 週賞記

免帳號、資料保存在本機的支付獎金記錄網頁。適用於 iPhone、Android 及桌面瀏覽器。

## 使用方式

- 消費：點按三個金額位置，選擇每次抽獎的獎金。
- 核銷：點按獎金劃線，再按取消；點原總額可一次核銷該 App 尚未核銷的全部獎金。
- 設置：加入或移出支付 App，使用箭頭排序；桌面亦可拖拉。
- 每週重置：所有獎金歸零，保留名單和排序；可恢復最近一次有效重置前的金額及核銷狀態。
- 備份：從設置匯出 JSON。匯入會取代目前記錄，原記錄會先另存為匯入前備份。

金額均為澳門元。摘要包含已移出顯示名單的 App，以免遺漏尚未使用獎金。0 表示零獎金；本版本沒有另外區分「尚未抽獎」。期間按手動重置增加，不會按星期自動清除資料。

## 加入主畫面

iPhone 可用 Safari 的分享選單加入主畫面。Android、Windows、macOS 的 Chrome 可從瀏覽器選單使用可用的安裝／加入主畫面選項。須透過 HTTPS 開啟；首次載入完成離線快取後可離線記錄。

## 資料保存

各裝置及瀏覽器分開保存，不會自動同步。共用同一瀏覽器設定檔亦會共用資料。清理網站資料、私密瀏覽或系統儲存管理可能導致資料消失，請定期匯出備份。資料不會上傳至本 GitHub 儲存庫。本工具只記錄核銷狀態，不操作支付帳戶。

## 發佈

本專案毋須安裝依賴或建置。於 GitHub 的 Settings → Pages，選擇 Deploy from a branch、main、/(root)，儲存後等待發佈成功。

網址：https://joetou.github.io/payment-rewards/

此網址僅在 GitHub Pages 部署成功後生效。若使用 GitHub Actions，另有本機交付的 pages.yml 可供選用，不應同時啟用兩種發佈方式。

更新程式時須同步更新 sw.js 的快取版本。舊分頁關閉後才啟用完整新版本，避免混用檔案；使用者記錄不隨程式更新清除。

## 圖示來源

銀行及支付工具圖示來自其官方發佈者在 Apple App Store 的產品頁，來源及取得日期列於 ASSET-SOURCES.json。圖示及商標屬各權利人所有。工銀及廣發採用銀行手機 App 圖示，非獨立支付子功能標誌；支付寶採用通用 Alipay App 圖示。本工具並非銀行或支付機構的官方產品。
