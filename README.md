# 週賞記

免帳號、本機儲存的支付獎金記錄網頁，適用於 iPhone、Android 及桌面瀏覽器。

公開網址：https://joetou.github.io/payment-rewards/

## 使用方式

- 消費：點按金額位置，記錄每個支付 App 三次抽獎的獎金。
- 核銷：點按獎金劃線，再按取消；點待核銷金額可一次核銷該 App 剩餘獎金。
- 統計：先列過往各期中獎及已核銷總額，再向下查看各期全部支付 App 的唯讀快照，橫線代表已核銷。
- 設置：加入、移出及排序支付 App，亦可匯出或匯入完整備份。

金額均為澳門元。摘要及歷史包括未放入顯示名單的支付 App。0 表示零獎金，沒有另行區分「尚未抽獎」。

## 自動換期

按澳門時間，每週五 00:00 開始新一期；期間為週五至緊接週四，例如2026-10-23至2026-10-29。網頁開啟時會於邊界換期，回到畫面或操作前亦會檢查；關閉時則在下次開啟補做。

換期會把全部支付 App 的三項金額、核銷狀態、名稱及當時排序保存為歷史，再把本期獎金清零。隔數週才開啟時，中間沒有記錄的週以零元保存。畫面只在完整歷史及清零後狀態成功寫入後更新，儲存失敗會保留原資料並停用修改。

期間按裝置時間判斷，請保持裝置日期正確。毋須人手重置；已移除舊版每週重置及恢復按鈕。歷史只供查看，本期操作不會改動歷史。

## 舊資料升級

v0.4使用資料格式v2及獨立儲存鍵。首次升級會保留v1原資料，再建立v2記錄，避免舊版視窗覆寫新歷史。舊版現有記錄按最後儲存時間歸入相應期間；舊版沒有確切週期資料，不能追溯重建未保存的多期紀錄。

如舊版尚有手動重置快照，會另外保存為「舊版手動重置快照（日期未記錄）」，不納入按期合計。備份匯入支援v1及v2，舊期間會先歸檔；匯出涵蓋本期及全部歷史。匯入會取代目前資料，原資料先另存為匯入前備份。

## 資料保存及安裝

各裝置及瀏覽器分開保存，不會自動同步。共用同一瀏覽器設定檔亦會共用資料。清理網站資料、私密瀏覽或系統儲存管理可能導致資料消失，請定期匯出備份。資料不會上傳至GitHub儲存庫。本工具只記錄核銷狀態，不操作支付帳戶。

iPhone可用Safari的分享選單加入主畫面。Android、Windows及macOS的Chrome可從選單使用可用的安裝／加入主畫面選項。首次載入完成快取後可離線使用。更新後如仍見舊版，關閉所有週賞記視窗再開啟，不需清除網站資料。

## 發佈及素材

本專案毋須建置。GitHub Settings → Pages → Deploy from a branch → main → /(root)。更新程式須同步更新sw.js快取版本；舊視窗關閉後啟用完整新版本。

銀行及支付工具圖示來自官方發佈者的Apple App Store頁，來源見ASSET-SOURCES.json。活動banner由使用者提供。圖示及商標屬各權利人所有，本工具並非銀行或活動主辦機構的官方產品。

豐付寶參加本活動的依據：https://www.taifungbank.com/en/promotion/1875 。活動規則以官方最新公佈為準。
